# The Code — Demo Site

Blank starter scaffolded in the standard demo format (matches the OQ stack).

**Stack:** Next.js 16 (App Router, TypeScript) · React 19 · Tailwind CSS v4 · Lenis (smooth scroll) · GSAP · Framer Motion · Three.js · clsx + tailwind-merge (`cn()` helper in `lib/utils.ts`).

## Getting Started

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Edit `app/page.tsx` to start building; the page auto-updates.

## Structure

- `app/` — App Router pages, layout, and global styles (`globals.css`).
- `lib/utils.ts` — the `cn()` class-merge helper.
- `components/` — shared UI (add as needed).
